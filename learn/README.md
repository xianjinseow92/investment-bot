# learn/

The owner's teaching workspace for investing basics, run with Matt Pocock's `/teach` skill (`.claude/skills/teach/`). Type `/teach` in a session to continue.

- `MISSION.md`: why we're learning; every lesson ties back to it.
- `QUESTIONS.md`: the question parking lot. Every new question goes here first, tagged **now** or **later**.
- `lessons/`: one short HTML lesson per idea, in order. Open in a browser.
- `reference/`: cheat sheets to come back to.
- `GLOSSARY.md`: terms the owner has shown they understand (not a dictionary to learn from).
- `learning-records/`: what has been understood, so the next lesson starts in the right place.
- `RESOURCES.md`: trusted sources. `NOTES.md`: how the owner likes to be taught.

The project's own glossary (`../GLOSSARY.md`) is for the bot's code and messages; this one is for learning. Where they share a term (order, fill), they agree.
