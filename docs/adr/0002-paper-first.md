# Paper first: no real money until the strategy beats the benchmark

No real money is used until a strategy has run on a paper account for at least three months and, after fees, beaten the benchmark with a smaller maximum drawdown. If no strategy manages that, the fallback is a plain automatic monthly purchase of an index fund, which the owner accepts as a good outcome. This is a rule about the project, not visible in the code, so it lives here. (Agreed 28 Oct 2026.)
